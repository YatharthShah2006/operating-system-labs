Q5. The last entry points to a block which in turn contains 256 more data block entries.

    A file's data blocks need not be contiguous because they are accessed via pointers hence there is no need for contiguity. Also, it's not necessary that all the blocks are allocated at once, later blocks are allocated as and when needed.
